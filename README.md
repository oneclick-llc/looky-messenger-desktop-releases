# Looky Messenger desktop

Installers for Looky Messenger and the feed the installed app updates from.
Download the latest build on the [Releases](../../releases/latest) page:

- **macOS** (Apple Silicon and Intel): `Looky-Messenger-<version>-mac-universal.dmg`
- **Windows** (x64): `Looky-Messenger-<version>-win-x64-setup.exe`

The app checks this repository for a new version and installs it on the next
restart. Each file has a `.sha256` next to it.

The source code is not here; this repository holds releases only.
